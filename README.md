    Описание Работы алгоритма:
1. Читаем символы регулярного выражения
2. если это
буква алфавита, то добавляем язык, состоящий только из этой буквы на стек 
3. иначе снимаем со стека 1 или две последних подъязыка 
(в зависимости от того, какой оператор - унарный * или бинарный + или .)
4. рассматриваем подъязык, который получается при применении
данной операции и для него храним какое самое длинное слово из букв Х
может быть в этом языке в принципе, и какой самый длинный конец из букв Х
может быть у слова в этом языке
5. В итоге - если изначальная запись регулярного выражения
была корректная, то должен остаться один объект на стеке - итоговый язык.
6. У этого объекта смотрим на поле, которое отвечает за максимальное количество
букв Х в конце слов этого языка - это и будет наш ответ.

В коде реализована логика непереполняемых целочисленных переменных - у которых область
значений - {-оо, Z, +о} Чтобы обрабатывать случаи, когда получаются сколь угодно длинные
последовательности из Х. 

    Доказательство корректности:
По индукции, 
База: для всех языков, состоящих только из 1 буквы верно, что поля length и end_length_ объекта 
subLand хранит верное значение ответа для такого языка - 1 если это язык из буквы Х, 0 иначе.
Переход - очевиден:
1. Если итоговый язык получился как конкатенация предыдущих - то length получается как сумма длин слов
принадлежащих этим языкам, состоящим только из символов Х. end_length получается так:
это либо слово первого языка заканчивается на отрезок из букв Х, а слово из второго языка состоит полностью из
букв Х, либо просто второе слово заканчивается на сколько-то букв Х, если нет слова во втором языке, состоящего
из букв Х. 
2. Если итоговый язык - результат А + Б где А и Б языки, для которых верно предположение индукции, то поля
length и end_length_ итогового языка хранят максимум из соотв. значений у А и Б, это корректно,
так как А+Б - объединение множества слов этих языков.
3. Если итоговый язык - получен из языка А звездой Клини, то тоже все очевидно - если в А было слово, состоящее
только из Х (где есть хотя бы 1 Х, пустое слово не подходит) то можно получить сколь угодно длинное слово из Х. 
Иначе самое длинное отрезок из Х в конце слов у языков А и А* будет иметь одинаковую длину.

   
    Асимптотика:
Асимптотика - один проход по регулярке, т.е. O(len(alpha)), так как все остальные функции это просто элементарные
операции с полями подъязыков.
